# Plan for #21: `hali relink` and move detection on `add`

Approved by the human. Contract wording is in the "Groomed contract (approved)" section of issue #21; the spec (`docs/spec.md` §6, §9.1) is the behaviour source. Implementer: opus. Security-reviewer required (touches `src/storage/`, `src/paths/`, reads file content).

## Approach

- New `src/core/relink.rs`: `search(ctx, store, roots, walk, stat, hash)` with pure `pub(crate) fn match_moves(missing, candidates)`; `explicit(ctx, store, id, path, byte_size, hash, force)`.
- `core::resource::check_moves(store, files, stat)` called by the CLI before `add_all` unless `--new`; shared `missing_resources`, `Error::possible_move`, `Error::hash_mismatch`.
- `storage::inspect_bounded(path, limit)` with `InspectError::TooLarge` (read capped at recorded size + 1).
- `paths::files_dir(env, configured)`; `Config.files_dir` / `[files] dir`.
- `src/core/schemas/relink.json` (SCHEMAS 25 to 26, four `oneOf` branches); `error.json` branches for `POSSIBLE_MOVE` and `HASH_MISMATCH`.
- CLI: `Relink` arm; `--new` on `Add`; thin passthrough.
- Spec: §9.1 **Relink:** paragraph, §9.8 prompt, §2.1, §4.1.
- Older tests to update: the 25-name schema lists (cli_refresh, cli_relation, cli_type, schema_contract, cli_schema, core_schema); CONFIG_INVALID fix text in `tests/cli_scan.rs` and `tests/cli_error_text.rs`; dry-run guard row `("relink","store",&["relink","--root","src/ontology"])`.

## Decisions (human-approved)

1 empty files excluded from matching and POSSIBLE_MOVE (goal row 24); 2 full `files.dir` chain here; 3 explicit relink of a non-Missing Resource allowed; 4 `--force` asks only when content differs; 5 POSSIBLE_MOVE before UNKNOWN_TYPE/UNKNOWN_CONCEPT; 6 walk skips not reported; 7 unusable default roots skipped silently.

## Defined (test-author notes)

- The issue, the plan and the spec do not fix these; the tests do (change them with the human if the wording should differ). Output of a search: `schema_version`, `roots`, `counts{relinked,ambiguous,unmatched}`, `relinked[{resource,from}]`, `ambiguous[{resource,candidates}]`, `unmatched[<record>]`, `truncated`; of an explicit relink: `schema_version`, `resource`, `from`, `refreshed`. `POSSIBLE_MOVE` details `{path,resources}`; `HASH_MISMATCH` details `{resource,path,expected,actual}`; the exact messages, fixes and suggested commands are in the locked envelope goldens. Prompt `relink resource <id> "<title>" <new path>? [y/N] `. A Missing Resource recorded as empty is not matched; a candidate is never a path some Resource records; a file under several roots counts once; the first defined entry of the `files.dir` chain is the only default root, and if it is not a directory there is none; an unusable explicit `--root` is a usage error.
- Seams (see the headers of `tests/core_relink.rs` and `tests/cli_relink.rs`): `core::relink::{search, explicit}` with `walk: FnMut(&str) -> Vec<Walked>` and `hash: FnMut(&str, u64) -> Option<Hashed>` (the cap is the recorded size, the read at most cap + 1 bytes), `resource::check_moves(store, files, stat)`, `Config.files_dir: Option<String>`, `storage::inspect_bounded(path, limit)` with `InspectError::TooLarge`.
- The goal compiles only with the `goal` feature, so the static gate stays green. Every test passes against a throwaway prototype of this contract (28 core, 53 CLI, 28 schema, 5 storage) that is not part of this commit.
- Older tests the implementer updates (not goal-owned): the 25-name schema lists (`tests/cli_refresh.rs`, `cli_relation.rs`, `cli_type.rs`, `cli_schema.rs` with `tests/snapshots/cli_schema__schema_list_json.snap`, `core_schema.rs`, `cli_describe.rs`, `cli_find.rs`, `cli_forget.rs`, `cli_concept_manage.rs`), the CONFIG_INVALID fix text (`tests/cli_scan.rs`, `tests/cli_error_text.rs`), help-text snapshots, and the `relink` row of `tests/dry_run_guard.rs`. `scan_schema_is_listed` in `tests/schema_contract.rs` was relaxed to accept either neighbour of `scan`.
